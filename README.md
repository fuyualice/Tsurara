# Tsurara

ホワイトボードの定型の前置きを、マウスだけで入力するための小さなパレットです。

```
05:12 tel&mail 田中→佐藤 ← ここまでをパレットで入力し、続きの本文は自分で打つ
```

パレットをクリックしても Discord の入力欄のカーソルはそのまま残るので、ボタンを押したらすぐ本文を打てます。
**Enter（送信）は送りません。** 送信は必ず自分で行ってください。

## 動作環境

- Windows 10 / 11（64 ビット）
- インストール不要。フォルダごとコピーして `Tsurara.exe` を起動するだけです

## 初めて起動するとき

1. [リリースページ](https://github.com/fuyualice/Tsurara/releases/latest)から `Tsurara-<バージョン>.zip` をダウンロードして展開し、`Tsurara` フォルダを好きな場所（例: ドキュメントの下）に置きます
2. `who` フォルダ（Who の候補）を、`Tsurara` フォルダの中（`Tsurara.exe` と同じ場所）に置きます。zip には含まれていないので、用意されたものをコピーするか、自分で作ってください（書き方は「[Who の候補を書く](#who-の候補を書くwho-フォルダ)」）
3. `Tsurara.exe` を起動します

署名のないアプリなので、初回は「**Windows によって PC が保護されました**」という青い画面が出ることがあります。そのときは次のように進めてください。

1. 「**詳細情報**」をクリック
2. 下に出てくる「**実行**」をクリック

2回目からは表示されません。

## 配布フォルダの中身

```
Tsurara.exe     アプリ本体
settings.json      既定の設定
who\               Who の候補（.txt 1ファイルが1タブ）。zip には含まれません
README.md          このファイル
```

## 使い方

1. `Tsurara.exe` を起動します。パレットが常に最前面に表示されます
2. Discord の入力欄をクリックして、カーソルを置いておきます
3. パレットで **How** を選び、**Who** を2回押します（1回目が from、2回目が to）
4. Who の2回目を押した瞬間に、前置きが Discord の入力欄に貼り付けられます
5. 続けて本文を打ち、Enter で送信します

### パレットの見方

```
[⚙]                      [✕]   ⚙ 設定 / ✕ 終了（新しい版があると間に表示）
      2026/10/05 (Mon)
         05:12:33              時計
┌──────────────┐
│ 入力内容          │ [クリア]   これから貼り付ける内容（プレビュー）
│ 05:12 tel 　→　   │
└──────────────┘
When  [now] [時刻を指定]
How   [tel] [mail]
Who   [タブ1] [タブ2] …
      [田中] [佐藤] …
```

- **入力内容**: 組み立て途中の内容です。まだ選んでいない部分は `＿` で表示されます。途中の内容は Discord には送られません
- **クリア**: How・Who の選択をやり直します（When はそのまま）
- パレットの余白をドラッグすると移動できます。終了時の位置は次回も使われます

### When（時刻）

- **now**: 貼り付けた時点の現在時刻を使います（既定）
- **時刻を指定**: 入力欄をクリックして時刻を打ち、Enter で確定します
  - `14:30`、`1430`、`930`（9:30）、`14`（14:00）のどれでも入力できます
  - Esc で取り消し。確定または取り消しすると、Discord に自動で戻ります
  - 指定した時刻は、貼り付けた後も［クリア］の後も残ります。同じ時刻で何件も続けて入力できます。現在時刻に戻すときは **now** を押してください
- 時刻の入力中だけはパレットがアクティブになります（キーボード入力のため）

### How

- `tel` と `mail` から1つ以上選びます。もう一度押すと選択が外れます
- 両方選ぶと `tel&mail` になります（押した順に関係なく、この順番です）

### Who

- タブで候補のグループを切り替えられます。from と to は別のタブから選んでも大丈夫です
- Who を先に2回選んだ場合は、How を1つ押した時点で貼り付けます

## Who の候補を書く（who フォルダ）

`who\` フォルダに `.txt` を置くと、1ファイルが1タブになります。

```
who\
  1_チーム.txt  → タブ「チーム」（1番目）
  2_事務.txt    → タブ「事務」（2番目）
```

ファイルの中身は1行に1人です。

```
# 「#」で始まる行と空行は無視されます
田中
佐藤
鈴木
```

- 文字コードは **UTF-8** で保存してください（メモ帳の既定のままで大丈夫です）
- タブはファイル名順に並びます。順番を決めたいときは `1_チーム.txt` のように先頭に「番号＋`_`」を付けてください（番号はタブ名に表示されません）
- 前後の空白は無視され、同じ名前が重複していても1つにまとめます
- **ファイルを書き換えたら、アプリを再起動してください**（起動時に読み込みます）

## 設定

### パレットから変える（⚙ ボタン）

| 項目 | 内容 |
|---|---|
| テーマ | システム（Windows に合わせる）／ライト／ダーク |
| 文字サイズ | 小・中・大、または［−］［＋］で 1 ずつ（10〜32） |
| 時計 | 表示／非表示 |

選んだ内容は自動で保存され、次回も使われます。保存先は `%APPDATA%\Whiteboard\` です（フォルダ名はアプリの開発時の名前のままです）。

### 設定ファイル

設定は次の順に読み込まれ、後のものが優先されます。

1. アプリに組み込みの既定値
2. exe と同じフォルダの `settings.json`（全員共通の既定値）
3. `%APPDATA%\Whiteboard\settings.json`（自分だけの設定。⚙ で変えた内容もここに保存されます）

```json
{
  "timeFormat": "HH:mm",
  "template": "{time} {how} {from}→{to} ",
  "how": ["tel", "mail"],
  "clipboardRestoreDelayMs": 150,
  "theme": "system",
  "fontSize": 16,
  "showClock": true,
  "checkForUpdates": true
}
```

| キー | 内容 |
|---|---|
| `timeFormat` | 時刻の書式（例: `HH:mm`） |
| `template` | 前置きの形。`{time}` `{how}` `{from}` `{to}` が置き換わります。末尾のスペースは本文をすぐ打てるようにするためのものです |
| `how` | How の候補 |
| `clipboardRestoreDelayMs` | 貼り付け後、クリップボードを元に戻すまでの待ち時間（ミリ秒、0〜5000） |
| `theme` | `system` / `light` / `dark` |
| `fontSize` | 文字サイズ（10〜32） |
| `showClock` | 時計を表示するか（`true` / `false`） |
| `checkForUpdates` | 新しい版が出ていないか確認するか（`true` / `false`） |

書きたい項目だけ書けば十分です。ファイルが壊れていたり値がおかしかったりする場合は、その項目だけ既定値で起動します。

## クリップボードについて

貼り付けはクリップボード経由で行います。

- 貼り付ける直前にクリップボードの**テキスト**を退避し、貼り付け後に元に戻します（画像などテキスト以外の内容は戻りません）
- 貼り付ける内容は Windows のクリップボード履歴（Win+V）やクラウド同期には残りません

## 困ったとき

| 症状 | 対処 |
|---|---|
| 前置きではなく、直前にコピーした内容が貼り付けられる | PC が重いと起きることがあります。`%APPDATA%\Whiteboard\settings.json` に `"clipboardRestoreDelayMs": 300` のように書いて待ち時間を長くしてください |
| 何も貼り付けられない | Discord の入力欄にカーソルがあるか確認してください。管理者権限で動いているアプリには貼り付けられません |
| Who が表示されない | `who\` フォルダが exe と同じ場所にあるか、ファイルの拡張子が `.txt` か、UTF-8 で保存されているかを確認し、アプリを再起動してください |
| パレットが見当たらない | 画面外に出た場合は、次回起動時に画面内へ戻ります。`%APPDATA%\Whiteboard\window.json` を削除すると画面中央に表示されます |

## 新しい版に更新する

新しい版が公開されると、パレットの一番上（⚙ と ✕ の間）に「**新しい版 v0.2.0 があります**」と表示されます。
アプリの起動時に1回、インターネット経由（GitHub）で確認しています。起動したままの間に出た新しい版は、次に起動したときに表示されます。自動でダウンロードや更新はしません。

1. 「新しい版 … があります」を押すと、ダウンロードページがブラウザで開きます。`Tsurara-<バージョン>.zip` をダウンロードして展開します
2. パレットの ✕ でアプリを終了します
3. 展開した `Tsurara` フォルダの中身（`Tsurara.exe`・`settings.json`・`README.md`）を、今使っている `Tsurara` フォルダに上書きコピーします。**フォルダごと置き換えないでください**（zip には `who\` が入っていないので、置き換えると Who の候補が消えます）
4. `Tsurara.exe` を起動します

⚙ で変えた設定やパレットの位置は `%APPDATA%\Whiteboard\` に保存されているので、置き換えても消えません。
`who\` はそのまま残ります。Who の候補を変えるときは、`who\` の `.txt` を書き換えるか差し替えて、アプリを再起動してください。

確認を止めたいときは、`%APPDATA%\Whiteboard\settings.json` に `"checkForUpdates": false` と書いてください。

## アンインストール

配布フォルダと `%APPDATA%\Whiteboard\` フォルダを削除してください。
